{%- comment -%} Inline an SVG figure from _includes/figures/ so the site's CSS custom properties reach inside it. An would not: a referenced SVG is a separate document and var(--accent) does not cross that boundary, so the figure would have to carry its own copy of the palette. Usage, from a draft in writing/ or a post in _posts/: {% raw %}{% include figure.html src="answer-twice-timeline.svg" alt="One sentence, for a screen reader" caption="What is plotted. Not the verdict." %}{% endraw %} Keep the example inside this comment tag. In an HTML comment Liquid still parses it, and figure.html would include itself until the stack blew. {%- endcomment -%}
